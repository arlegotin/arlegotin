## R&D

- [AffineFlow](https://github.com/arlegotin/physical-time-consistency): learning how a robot responds over time, with a small control-cost gain in simulation.
- [FamilyTiles](https://github.com/arlegotin/FamilyTiles): 20% less weight storage for two related language models, with exact reconstruction and measured inference limits.
- [ExactKV](https://github.com/arlegotin/ExactKV): lossless LLM cache compression, showing when recovery costs more memory than compression saves.
- [DAV](https://github.com/arlegotin/DAV): an experiment in verifying AI-written code without counting the same evidence twice.
- [RBC](https://github.com/arlegotin/RBC): keeping relationships between uncertain facts so decisions can show when the evidence isn’t enough.
